OYO 10X — brand assets
======================

Drop two files into this folder and the application picks them up
automatically. No code changes and no rebuild of the source are needed;
just refresh the browser (or re-run `npm run build` for the production
bundle).

  candidate.png   The candidate photograph from the cover page.
                  Portrait orientation. Anything from 600x800 upwards
                  looks right; it is displayed with the head and
                  shoulders toward the top of the frame.

  campaign-poster.png
                  The full campaign poster shown below the login form.

  logo.png        The official OYO 10X crest/logo, on a transparent
                  background. Square or near-square.

Until these files exist the application falls back to a drawn SVG crest
and a labelled placeholder, so nothing breaks and no layout shifts.

Colours taken from the cover, already applied across the interface:

  Deep green    #062E1A   page furniture, sidebar, hero panel
  Forest green  #0E4A2B
  Gold          #C9A227   rules, accents, the crest
  Light gold    #F0D98A
  Cream         #F5EFE2   hero text, section grounds
